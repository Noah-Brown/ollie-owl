Personal agent mascot

Ollie, a saw-whet owl

Ollie is modelled on the northern saw-whet owl, one of the smallest owls in North America. Ollie has layered soft plumage, wings built from individual feathers, and glossy yellow eyes. Like a real owl, Ollie turns its head to look at things. In chat, Ollie perches on a branch that doubles as the loading bar.

Watches your pointer, blinks slowly, and sometimes swivels its head to look around.

Use it in your app

Everything is in one module, ollie.js, built on three.js. Give it a canvas and a mode: 'bar' for the loading bar or 'perch' for a square avatar. It stops drawing while off screen, uses fewer feather layers on small canvases, and slows down for people who have reduced motion turned on.

<script type="importmap">
{ "imports": {
  "three": "https://cdn.jsdelivr.net/npm/three@0.169.0/build/three.module.js",
  "three/addons/": "https://cdn.jsdelivr.net/npm/three@0.169.0/examples/jsm/"
} }
</script>
<script type="module">
  import { OllieMascot } from './ollie.js';

  const ollie = new OllieMascot(document.querySelector('#loader'), { mode: 'bar' });
  ollie.setState('thinking');   // no progress yet: flies laps
  ollie.setProgress(2 / 5);     // step 2 of 5: hops to 40%
  ollie.setState('done');       // fluffs up at the end of the branch
  ollie.dispose();              // once the reply has arrived
</script>
